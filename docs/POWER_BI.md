# Minimal Power BI Plan

Use Power BI Service/browser.

## KPIs
- Total Shipments
- Active Excursions
- Critical Excursions
- Affected Lots
- Unknown Temperature %
- Investigation SLA Breaches

## Visuals
1. Temperature timeline
2. Excursions by severity
3. Affected lots by disposition/risk
4. Late / duplicate / missing events
5. Investigation SLA

## Slicers
Date, Shipment, Product/Storage Profile, Severity, Status.

Keep the report intentionally small. It proves analytical correctness and
operational visibility.
