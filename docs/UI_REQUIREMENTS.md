# UI Requirements

Use a restrained pharmaceutical/clinical aesthetic.

Principles:
- minimal
- professional
- clean
- calm
- data-first
- pharma/medicine visual language
- avoid generic AI-dashboard appearance
- avoid excessive gradients, rainbow colors, oversized cards, emojis and noise
- subtle glass surfaces only when useful
- strong typography and whitespace
- clear severity/status indicators
- temperature timeline as a primary visual

Use subtle clinical surfaces and deep pharmaceutical green/blue-gray accents.
Reference the polish of seal.run for inspiration only. Do not copy branding
or assets.

Pages:
- Dashboard
- Shipments
- Shipment Detail
- Excursion Detail
- Investigation
- Audit History
- Admin/Configuration
